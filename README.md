# 我的工作小助手

一个双击就能用的工作整理小工具，功能包括：

- ✏️ **每日记录** —— 快速记下每天做了什么、花了多少时间、归属哪个项目
- 📊 **项目进度** —— 为每个项目建立任务清单，自动计算完成百分比
- 📄 **周报生成** —— 一键把一周的工作记录汇总成周报草稿，可复制、可下载
- 💾 **数据备份** —— 一键导出备份文件，换电脑也能恢复

## 怎么使用

直接双击 `index.html` 文件，会用浏览器打开，即可使用。

数据自动保存在浏览器里，建议每周点一次「导出备份」，把下载的 JSON 备份文件保存好。

## 这个仓库是干嘛的

这是我的第一个 GitHub 仓库，用来存放这个小工具的代码和备份，相当于云端保险柜：电脑坏了、换电脑了，都能从这里找回来。

## 怎么更新到 GitHub

以后让 AI 助手帮忙，或者自己打开命令行（按 `Win + R`，输入 `powershell`），执行：

```
cd "E:\桌面\我的工作小工具"
git add .
git commit -m "更新工作数据"
git push
```
